# Day 16 – CSV & JSON

## CSV

CSV stands for Comma-Separated Values.

Used for storing tabular data.

### Important Functions

csv.reader()
csv.writer()
csv.DictReader()
csv.DictWriter()

## JSON

JSON stands for JavaScript Object Notation.

It is commonly used for storing and exchanging structured data.

### Important Functions

json.load()
json.dump()
json.loads()
json.dumps()

## Important Difference

dump()  → Python object to JSON file
load()  → JSON file to Python object

dumps() → Python object to JSON string
loads() → JSON string to Python object

## Key Learning

CSV is useful for tabular data.

JSON is useful for structured and nested data and is widely used when communicating between applications and APIs.
